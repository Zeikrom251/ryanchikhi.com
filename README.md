# Portfolio, Ryan Chikhi

My portfolio in French and English, live at [ryanchikhi.com](https://ryanchikhi.com).
Built with Next.js, TypeScript and SCSS.

## Run it

```bash
pnpm install
pnpm dev
```

## Edit it

- Content: `src/data/resume.ts`
- Buttons and labels: `src/i18n/locales/fr.json` and `en.json`
- Colours: `src/styles/_variables.scss`
